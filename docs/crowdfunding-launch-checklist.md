## 3. リターン設計（★★★）

> 決定済みリターン（LP `src/components/Crowdfunding.tsx` に反映済）。
> 利用者（B2C）向けは価格昇順、プロ（B2B）向けは別枠で表示している。

| 区分 | プラン | 価格 | 主な特典 |
|---|---|---|---|
| B2C | 創業サポーター応援プラン | ¥3,000 | サポーターバッジ／ポイント¥1,000相当／月次レポート／サポートコンテンツ |
| B2C | シルバー会員権プラン | ¥8,000 | シルバー会員資格／3%割引／優先マッチング月1／創設バッジ |
| B2C | ゴールド会員権プラン | ¥25,000 | ゴールドアクセス／5%割引／繁忙期優先予約／専用サポート／特別バッジ |
| B2C | プラチナ創業メンバー権 | ¥50,000 | プラチナ資格／8%割引／指名サポート／ベータテスター／年次集会招待 |
| B2B | プロ登録優待パック | ¥30,000 | 3ヶ月ブースト¥17,940相当／手数料50%OFF(3ヶ月)／早期プロバッジ／専任サポート |

### 前提アップデート（2026-05-19）

- CAMPFIRE **掲載審査 通過済**。公開後の**リターン追加・編集は可能**（→ 創業先行枠を後から足せる）。
- 「¥1,000相当」「¥17,940相当」は**実売価格の根拠あり**（社内確認済）。→ 表記は維持可。ただし景表法上、**比較対象価格＝当社通常提供価格である旨と算定根拠・適用条件**を CAMPFIRE ページに明示すること（根拠があっても表示方法が不適切だと違反になり得る）。

### 数量限定「創業先行枠（超早割）」推奨設計 ★最重要・初速の核

> 公開72hの初速を作る唯一の装置。LP には先着限定の予告枠を反映済（`Crowdfunding.tsx`）。
> 下記の数値（¥・枠数）のみ社内決定して CAMPFIRE にリターン追加する。

- [ ] **2段構成で設計**
  - 創業超早割（最先着）：先着 **___ 名**（推奨：少数。早期完売の達成感が初速を生む）。内容＝シルバー or ゴールド相当＋上乗せ特典（例：割引率+◯%／限定バッジ／公開記念ノベルティ）を**通常より低い ¥___**
  - 早割（次点）：先着 **___ 名**。超早割完売後に出る中間価格 **¥___**
- [ ] **価格逆転させない**：超早割 < 早割 < 通常（…＜プラチナ¥50,000）
- [ ] **原価試算**：割引・上乗せ後も粗利が残るか（手数料・決済手数料込み）
- [ ] **CAMPFIRE 個数制限機能**を使い「残り◯」を可視化（希少性の演出）
- [ ] **景表法表示**：「先着◯名限定」「販売期間」を明記。比較価格は「当社通常提供価格 ¥___ のところ」と算定根拠・条件付きで表示
- [ ] **公開オペ**：公開と同時に先行枠を表に出し、事前登録者へ「先着なので開始直後に」と通知（§4・§9と連動）

### 引き続きの推奨（任意・転換率向上）

- [ ] **サービス価値リターンの追加**：出張洗車の CF。「割引/バッジ/資格」中心に加え、**先行利用チケット・回数券・年間パス**等“実サービスを安く先取り”できる枠を足すと最も転換しやすい
- [ ] **割引特典の条件明示**：3%/5%/8%割引の適用期間・回数・対象サービス・無期限か否かを明記（無期限の永久割引は収支・規約リスク）
- [ ] **ポイント付与の資金決済法該当性**：「ポイント¥1,000相当」発行が前払式支払手段に当たらないか要確認
- [x] **B2CとB2Bの分離**：プロ登録優待パック(¥30,000)は LP で別枠表示済。CAMPFIRE 上でも別セクション/カテゴリで提示
- [ ] 各リターンの**原価・粗利**算出（手数料・決済手数料込みで赤字でないか）
- [ ] **役務提供時期**を現実的に設定（プロ採用・エリア展開のリードタイム反映）
- [ ] 提供エリアの明示（`src/data/prefectures.ts` の対応エリアと整合）
- [ ] 実現不可能・過大なリターンを設定しない（規約違反・未達トラブルの最大要因）
- [ ] 「応援のみ（リターンなし/お礼メール）」枠も用意
- [ ] 体験型（先行施工＋撮影協力）リターンはインフルエンサー施策と連動
